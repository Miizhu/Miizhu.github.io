凤凰曾栖(二) 选项交互

发表于2026-08-18|更新于2026-08-22|游戏
|总字数:1.5k|阅读时长:5分钟|浏览量:

简读

本篇介绍了Godot引擎从创建交互页面到游戏实现选项交互逻辑的过程。

技术栈

游戏引擎：Godot 4.7
编程语言：GDScript
渲染方式: Mobile Renderer

实现过程

实现角色走到门边会触发高亮

  1. 在我们的场景节点下新建一个Area2D节点（一个检测器，这边重命名为DoorInteractionArea），检测玩家是否进入，用来发出信号。
  2. 接着我们在该节点下新建一个CollisionShape2D节点，用来标注该Area2D的范围，这一步与上一篇文章中一样，将检查器面板中的Shape改成RectangleShape2D，然后画框就可以。
    因为我想要让能交互的物件明确标示，所以我还加了一个Line2D节点，颜色调成黄色把门框起来了。如果想实现跟我一样的效果，记得勾选检查器中的closed。

    完成节点设置后我们来编写脚本，真正实现交互逻辑。选中DoorInteractionArea节点，在检查器界面的上方，也就是菜单栏，选中【信号】这一栏，点击body_entered和body_exited，分别将这两个信号连接到根节点，也就是我们场景节点的脚本上。
    此时会出现两个函数
func _on_door_interaction_area_body_entered(body: Node2D) -> void:
func _on_door_interaction_area_body_exited(body: Node2D) -> void:

这时，我们将其调整为以下形式：

# func定义这是一个函数
# body:Node2D说明参数是body，类型是
func _on_door_interaction_area_body_entered(body: Node2D) -> void:
	if body == character:
		print("玩家靠近门")


func _on_door_interaction_area_body_exited(body: Node2D) -> void:
	if body == character:
		print("玩家离开门")

运行游戏进行测试，当玩家靠近门时观察Godot下方的输出，如果输出符合以上代码，则证明逻辑通顺
接下来我们做高亮显示，首先在脚本头部加入

# 定义高亮在脚本中对应的变量
@onready var door_highlight: Line2D = $DoorInteractionArea/Highlight

因为Godot引擎的Line2D本身自带了一些功能/属性
修改刚才的两个测试代码为

func _on_door_interaction_area_body_entered(body: Node2D) -> void:
	if body == character:
		door_highlight.show()

func _on_door_interaction_area_body_exited(body: Node2D) -> void:
	if body == character:
		door_highlight.hide()

此时，人物在靠近门时门会被黄框包裹，实现高亮。
还需要在函数_ready()中添加

door_highlight.hide()

因为高光一开始是不显示的

交互实现

首先我们要明确，我们这个交互需要什么样的效果。对于我这个项目而言，我需要人物在门边时才能交互，且交互界面弹出时人物不能移动。
我们打开Godot引擎，点击项目——>项目设置——>输入映射，添加新交互interact，绑定键位，我这边绑定的是空格键

在文件头添加变量

# var说明这是一个变量，：bool说明这个变量是一个布尔值。
# 这个变量用于控制门是否可以开关
var can_interact_with_door: bool = false

接下来将函数修改成这样

func _on_door_interaction_area_body_entered(body: Node2D) -> void:
	if body == character:
		door_highlight.show()
		can_interact_with_door = true


func _on_door_interaction_area_body_exited(body: Node2D) -> void:
	if body == character:
		door_highlight.hide()
		can_interact_with_door = false
#以下为新建
func interact_with_door() -> void:
    print("玩家与门交互")

func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("interact"):
        if can_interact_with_door:
		    interact_with_door()	
	return

当玩家走到门边按下交互键，有输出时说明逻辑已成立。

交互弹窗

接下来我们做交互的弹窗。

1.在场景根节点下新建CanvasLayer节点，改名为InteractionUI，这个节点负责交互界面的绘制。
2.接着在该节点下建立CenterContainer节点，它会保证接下来在这个节点下的节点绘制出来的内容居中放置。在检查器中将锚点预设改为整个。
3.接着我们在该节点下新建PanelContainer节点，控制在PanelContainer节点下的附属节点在一个框内
4.在PanelContainer下添加接待你MarginCotainer节点，让每一个选项框之间留有空隙。
5.在MarginContainer节点下添加VBoxContainer节点，让接下来的附属节点呈竖状排列。在下面添加节点Label，即让框内出现文字
6.接下来在VBoxContainer下添加附属节点XBoxContainer，这个节点让它下面的附属节点能够横排排列
7.添加两个Button节点，即选项
PS：Label节点和Button节点的检查器里都可以修改它们显示的文字

接下来打开脚本页面，在文件头加入

# 获取到DoorMenu这个节点，以便做逻辑
@onready var door_menu: PanelContainer = $InteractionUI/ScreenCenter/DoorMenu

接下来加入

# 这个函数是之前就有的
func interact_with_door() -> void:
    # 需要加入这一行
	door_menu.show()
	character.movement_enabled = false

# 关闭与门交互的菜单
func close_door_menu() -> void:
	door_menu.hide()

# 判断玩家是否按交互键
func _unhandled_input(event: InputEvent) -> void:
		
	# 如果按下关闭UI键，关闭UI
	if event.is_action_pressed("ui_cancel") and door_menu.visible:
		close_door_menu()
		return
	if event.is_action_pressed("interact"):
		if door_menu.visible:
			close_door_menu()
		elif can_interact_with_door:
			interact_with_door()
		return


因为选项弹出时，人物应该是不能移动的。
所以我们切换回之前建立的character_body_2d脚本，在文件头部加入

# 控制角色是否可移动
var movement_enabled: bool = true

在移动逻辑前面加入

# Vector2.ZERO是Godot自带的让速度变为0的函数
if not movement_enabled:
	velocity = Vector2.ZERO
	return

# 以下是整个移动逻辑的函数现在的样子
func _physics_process(_delta: float) -> void:
	if not movement_enabled:
		velocity = Vector2.ZERO
		return
	var direction := Input.get_vector(
		"move_left",
		"move_right",
		"move_up",
		"move_down"
	)
	velocity = direction * speed
    # 这个if是现在加入的
	if direction != Vector2.ZERO:
		facing_direction = get_direction_name(direction)
		sprite.play("idle_" + facing_direction)
	move_and_slide()

接下来切回主场景脚本，修改

# 与门交互的逻辑
func interact_with_door() -> void:
	door_menu.show()
    # 这行是新加的
	character.movement_enabled = false

# 关闭与门交互的菜单
func close_door_menu() -> void:
	door_menu.hide()
    # 这行是新加的
	character.movement_enabled = true

如此一来，我们便实现了打开弹窗和关闭弹窗了。

按钮交互

我们选中按钮节点，点击信号，将pressed()连接到bedroom，找到

func _on_walk_option_pressed() -> void:
# 加上
	close_door_menu()

如果选完选项之后， UI关闭，就说明逻辑成功了。
